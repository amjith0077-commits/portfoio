# Amjith P — Game Developer / 3D Modeler Portfolio

## Quick setup
1. Upload the contents of this folder to your GitHub Pages repository.
2. Open `index.html` locally to preview.
3. Replace the placeholder email, GitHub and LinkedIn links in `index.html`.
4. Replace `assets/resume.pdf` whenever you have a newer resume.

## Included media
- Gameplay video from the supplied Unity capture, compressed for web use.
- Eight 3D asset turntable clips supplied by Amjith.
- 24+ extracted showcase frames used as poster/gallery images.
- Resume PDF generated from the latest resume.

## GitHub Pages
For a user site, use a repository named `YOURUSERNAME.github.io`, then enable Pages from Settings → Pages → Deploy from branch.

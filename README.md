# Amjith P — GitHub Portfolio

A modern responsive portfolio website for a Unity / C# game developer.

## Files

- `index.html` — website structure and content
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll reveal and cursor glow
- `assets/` — place project screenshots, videos, icons and resume here

## Publish with GitHub Pages

1. Create a repository named `YOURUSERNAME.github.io`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. Open `https://YOURUSERNAME.github.io`.

## Customize

Search and replace:

- `Amjith P`
- `your.email@example.com`
- `https://github.com/yourusername`
- Project names/descriptions
- Skills

To add project images, replace the CSS backgrounds in `.visual-boat`, `.visual-city`, and `.visual-system` with your own images.
